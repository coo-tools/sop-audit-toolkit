# Contributing

Useful improvements and clear bug reports are welcome.

1. Open an issue describing the process-control problem or defect.
2. Create a focused branch such as `feat/review-notes` or `fix/action-ranking`.
3. Keep scoring logic in `src/core.js` and add or update tests in `tests/`.
4. Run `npm test` and complete the relevant checks in `TESTING.md`.
5. Open a pull request explaining the problem, decision, and test evidence.

Use concise commit messages that describe an outcome, for example `Improve priority ordering for control gaps`. Avoid unrelated changes in the same pull request.
