# Changelog

All notable changes to this project are documented here.

## [1.1.0] - 2026-09-07

### Added

- Process name, process owner, and review date fields
- Audit context in exported Markdown action plans
- Unit coverage for context normalization and context-aware exports

### Changed

- Browser persistence now stores checklist answers and audit context together
- Acceptance-test documentation now covers the context workflow

## [1.0.0] - 2026-08-10

### Added

- Weighted SOP control audit across four operating areas
- Section scores, maturity labels, and prioritized actions
- Local browser persistence and Markdown action-plan export
- Automated unit tests, continuous integration, acceptance-test documentation, and product preview
